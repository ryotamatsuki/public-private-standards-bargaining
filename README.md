# Public–Private Standards Bargaining under Differentiated Oligopoly

Independent theoretical-economics project on joint government/firm standards negotiations with differentiated Cournot market continuations.

## Research status
- Stage 0: GO TO AUDIT (2026-10-13). **This is not a novelty certificate.**
- Stage 1: source and mathematical audit in progress on a dedicated branch; main is the stable project entrypoint.
- No proposition about the full bargaining game is proved, and no manuscript or journal submission is authorized.

## Research question
Can divided public recognition and private technology-consent rights change the equilibrium standard or cross-border public/private coalition structure, compared against bargaining institutions matched on feasible contracts and downstream differentiated-Cournot payoffs?
