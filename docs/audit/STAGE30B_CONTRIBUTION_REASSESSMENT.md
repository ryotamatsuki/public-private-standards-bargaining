# Stage 30B — フルペーパー再構成の評価

## 結論

**現行モデルから、フルペーパーの核になり得る追加結果を構成できた。**
ただし、掲載価値が確認済みになったわけではない。Stage30の現行原稿に
対するNO-GOとStage31停止を保存する。今回の判断は「現行モデルを使う
一回の再構成には投資する価値がある」であり、投稿GOではない。

以前の「追加モデルよりnoteへの短縮を優先」という判断は、当時評価した
定理群に対するものだった。今回、モデルを一切追加せず、最適設計だけを
扱う厚生分析を全民間均衡の比較へ拡張できた。この新しい根拠に応じて、
full-paper候補を再評価する。元の監査を削除して結論を差し替えない。

## 何を追加で学べるか

民間標準の企業は、互換性投資を共同で増やせば利益を増やせるのに、一社
だけ増やしても互換性が上がらない。そのため、民間の最適設計だけでなく、
低投資の協調均衡も残る。ただし全ての低投資が残るわけではない。創業企業
には、私的開発をやめて公的導入を誘発する退出先がある（生産市場からの
退出ではない）。この政策fallback
が私的利益の下限を作る。一方、開発していない外部国には新しい導入費用が
かかり、その国の政治的拒否が別の境界を作る。提案権の拡大は、この二つの
境界に支えられた民間均衡集合を丸ごと排除する。結果として、制度改革が
どの旧均衡からでも世界厚生を下げない領域と、最悪の均衡を改善する代わり
に最良の均衡を失う領域を区別できる。

## 追加結果の価値を分ける

| 結果 | Stage29からの実質的な差分 | 経済的重要性・限界 |
|---|---|---|
| 全私的純粋SPEの必要十分条件 | 最適二社設計の構成から、低投資を含む全二社設計へ。三社私的SPEもunanimityまで排除 | 企業の共同最適化を均衡選択として置く必要がなくなる。min型協調不全自体は既知 |
| 全公的純粋SPEの厚生不変性 | 最終規格の一意性から、放棄投資ゼロと厚生・利益の同一性へ | 政策結果だけから厚生を推測する飛躍を閉じる。公的費用定義への依存は残る |
| 固定費上昇による私的均衡集合の拡大 | `a_R*`の比較静学とは違う、均衡集合の包含関係 | 「開発が高価なら私的投資が減る」とは別の政治的効果。選択投資量の予測ではない |
| 選択を固定しない制度厚生の鋭い条件 | 一つのRSとNNN→Mの比較から、全旧SPEとの比較へ | full-paper候補の最も強い結果。閾値自体は既存の`K_W`だが、普遍量化の意味が変わる |

最終結果は単なる`K_W-K_E=phi*a^2`の追加解説ではない。新たに必要なのは、
私的均衡の全域分類、公的均衡の厚生同一性、全私的均衡の厚生上限の証明である。
これらが揃って初めて「全ての旧均衡より新制度が弱く良い iff K<=K_W」という
条件を述べられる。

具体例：`eta=.14,K=.55`で、同じ狭い提案権制度に
`O(1,0),O(1,0),N`と`O(1,.5),O(1,.5),N`が共存する。前者は公的均衡より
世界厚生が`.106147...`低く、後者は`.048788...`高い。どちらも全域の
逸脱条件を満たす。規格のラベルRSだけでは厚生順位を決められない。

## フルペーパーにするなら主題を変える

主題候補は「民間の協調不全があるとき、公的標準化を成立させる制度改革は
厚生を改善するか」。二政府という数を中心に据える構成から、**政治的
fallbackが規律付ける投資均衡と、制度改革の最良・最悪厚生の比較**を中心に
据える構成へ改める。

必要な論文の流れは以下で足りる。

1. 問い、私的協調と政策fallbackの二つの力、親理論との正確な差分。
2. 現行モデルと指定された政府行動規則。
3. 全私的均衡の分類と、公的均衡の放棄投資ゼロ。
4. 提案権・可決要件による均衡集合の変化。既存の閾値定理をここに統合。
5. 固定費の政治的効果と、全均衡を対象とする厚生の条件・境界。
6. 仮定依存、負の頑健性診断、限定的制度解釈。

会計恒等式と多項式証明は必要な橋を残してAppendixへ移す。新しいモデル、
移転、補助金、国数、情報不完備、最適規格選択を追加する必要はない。
図は補足的な数値説明であり、本文の定理の代用品にしない。

## 最も強い採録理由と棄却理由

**採録審査に進める理由：** 政策変更の導入成功と厚生改善を分離し、任意の
内生的投資均衡に対して成立する条件を示す。私的設計を企業の共同最適解に
固定しない点で、現行原稿の診断が実質的に深くなる。研究としての追加投資は、
この結果群を一つの経済的問いにまとめるためなら正当化できる。

**最も強い棄却理由：** min型の協調不全と外部選択肢による参加条件は古典的
であり、均衡集合の厚生比較も一般的な集合比較の応用に見える可能性がある。
外部国が新たにKを負担する一方で創業企業のKが両経路で同じという費用設計が
比較静学を強く支える。費用付き公的導入・自由投票のStage30負の診断は消えて
いない。文献差分を「連続」「三国」「全域証明」だけで説明するなら、新たに
定理が増えてもfull-paper NO-GOの理由は残る。

私の現在の判断は、**無条件にnoteへ縮小する前に、この同一モデルの再構成を
一度だけ評価する価値がある**。現在の結果群は旧原稿より強い核候補である。
ただしフルペーパーとして採録推薦するには、新しいStage4AとStage6で、
最接近理論に対する実質差分が残ることを確認する必要がある。

## 終点と最小限の次工程

新しい仮定探索はここで止める。今回の結果群について一回の証明再監査と
定理吸収監査を行う。Gandal–Shy/Klimenko掲載版の未取得を確認済みにしない。
Cornes–Hartley、Caparrós–Finus、Li–Wolfstetter、Harstadとの比較を含める。

その監査を経ても掲載理由が「既知の弱いリンク協調をこの数値モデルで閉じた」
にとどまるなら、追加命題や新モデルで救済せず、noteまたはworking paperに
再構成する。反対に、全均衡を対象とする制度厚生の鋭い条件が独立した経済的
差分として残るなら、同じモデルだけでfull-paper改稿へ進む。

**現時点の区分：Stage4構成は追加成果あり／新Stage4A・6は未完了／
Stage30原稿のNO-GOは保存／Stage31投稿準備へは進まない。**
