## Discovery: material Stage-4 generic rule was incorrect
The production report originally wrote: RS→IS requires all six participants to strictly improve. This is FALSE at arbitrary original messaging profiles. An RS outsider may have already announced the target IS contract, without altering the realized RS contract, and so need not be a deviator to help form IS later. A losing/non-gaining outsider's action can still materially enable another coalition to deviate. Exact rational counterexample:
 g=7/50, v=3/10, κ=1/4, η=1/8, c0=3/10, h=3/20, f=7/20.
 Original signed RS12 s=33/40. Outsider G3,F3 preannounce IS s=17/40; old RS remains operative. Only its FOUR required signers change to IS(17/40), forming IS. Each changing firm's net profit increases ≈0.023956936 and changing government's national welfare increases ≈0.002086087; outsider firm profit falls ≈0.073552416 and outsider government's national welfare falls ≈0.095423265. All SPD matrices/positive Cournot outputs, incumbent RS IR, world welfare identity verified via Cramer's rule. The old six-gains test would incorrectly classify this valid 4-player deviation as blocked.

The error was explicitly fixed IN THE STAGE-4 DOCUMENT first (separate commit c3f9e646...), before this Stage-4A independent rerun. Correct complete rule: an alternative agreement is enforceable iff all essential actors' CURRENT/UPDATED messages match it; the PROPER deviating coalition consists of actors whose messages actually changed; strict-gain requirement binds only THOSE deviators. In a canonical signed RS profile where both outsider messages initially equal SQ, all six indeed must change to create IS, but this is not the general equilibrium profile domain.

- Welfare comparisons use same three destination unit populations, source network value in NS, worldwide owned firm profits and real integration setup costs deducted once. The claim compares separately modeled firm profits and national welfare in given strong-coalition contract outcomes; it is NOT a planner/first-best comparison.

## Stress and counterexample audit

Near-singular, output-corner, asymmetric countries, varying IS scale efficiency, or incomplete licensing-right configurations are excluded; outside their domains the original results MUST NOT be extrapolated.
